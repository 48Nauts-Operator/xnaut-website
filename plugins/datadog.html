D

Datadog

Query Datadog metrics, logs, traces, monitors and incidents.

Dev needs DD_MCP_DOMAIN source ↗

Connector

https://${DD_MCP_DOMAIN:-not-setup}/v1/mcp?referrer_ide=claude-code-plugin&plugin_version=0.7.14&toolsets=${DD_MCP_TOOLSETS:-}

An HTTP MCP endpoint. xNAUT talks to it directly; nothing is installed.

Credentials

  • DD_MCP_DOMAINrequired — you paste it once, into your own machine's plugin library
  • DD_API_KEYrequired — you paste it once, into your own machine's plugin library
  • DD_APPLICATION_KEYrequired — you paste it once, into your own machine's plugin library
DD_MCP_DOMAIN must be set to your Datadog site host, plus API and application keys.

Skills it ships

3 skills. The connector gives an agent the tools; a skill tells it when to reach for them.

  • ddconfig
  • ddsetup
  • ddtoolsets

How it reaches your agent

  1. The library holds it, with your credential, on your machine.
  2. You hand it to one agent with the + in that agent's header. No other agent gets it.

Two gates, on purpose. A chat turn never uses a plugin; a build run gets the ones that agent holds.

Provenance

Entry compiled from the public plugin registries, then run and described by 48Nauts — the setup note above is ours, and it exists because someone ran this and watched what it did.
