Work tracking sign-in required source ↗

Connector

https://mcp.linear.app/mcp

An HTTP MCP endpoint. xNAUT talks to it directly; nothing is installed.

What we measured

sign-in required. On 2026-08-16 we sent this endpoint an MCP initialize with no credentials and no headers, and that is what came back.

Not a security audit, not an endorsement, and not a heartbeat: it is one request on one date. An endpoint is a vendor's service, not an artifact we can pin, so it can behave differently tomorrow.

Credentials

None. It runs as soon as it is switched on.

Authorization: Bearer <token>. The hosted endpoint answered 401 at seed time, meaning it is alive and wants auth.

Skills it ships

None. The connector gives an agent the tools; a skill would tell it when to reach for them.

How it reaches your agent

  1. The library holds it, with your credential, on your machine.
  2. You hand it to one agent with the + in that agent's header. No other agent gets it.

Two gates, on purpose. A chat turn never uses a plugin; a build run gets the ones that agent holds.

Provenance

Entry compiled from the public plugin registries, then run and described by 48Nauts — the setup note above is ours, and it exists because someone ran this and watched what it did.
